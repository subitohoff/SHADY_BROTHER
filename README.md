# SHADY_BROTHER
Complete tool that allows running Evil Twin style Wi-Fi attacks with your own twist. It sets up a fake hotspot (any SSID you want) and attaches a captive portal where users are asked to log in or register. All captured data is stored locally for later analysis.

The tool also includes options to kick devices off the original network by sending crafted packets, making them more likely to connect to the fake AP.

This project is part of my engineering thesis in cybersecurity – made for research, educational and testing purposes only.
